📝 TaskFlow PRO

A simple and modern To-Do List web application built to organize and manage tasks efficiently.

🔗 Live Demo: https://to-do-list-pied-mu-74.vercel.app/

✨ Functions

* ➕ Add, edit and delete tasks
* 📋 Organize tasks by status
* 🎯 Set priority and category
* 📅 Add due dates
* ☑️ Manage subtasks
* 🔍 Search and sort tasks
* 📊 Track task progress
* 💾 Backup and restore tasks
* 📱 Responsive and user-friendly interface

🛠️ Built With

* HTML
* CSS
* JavaScript
* Antigravity
* Vercel
